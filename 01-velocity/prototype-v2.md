## v2 build

- **Shareable link:** https://first-90-days-watchtower.lovable.app
- **Before → after:** Insightful overview of accounts - actionable dashboard that allows users to be impactful and prioritize
- **What each pass changed:**
  - Add Interactivity: I included sorting that makes prioritization easier, for example by ARR at risk to save the richest accounts first, or by age, as the older the account gets, the time available to save it shrinks in the 90 days window.
  - Surgical Refinement: I made sure the accounts actions could be tracked, i.e. we could see at a glance which ones of the accounts had not been actioned in a long time and which specific actions needed to be taken. Users can mark a task (such as schedule onboarding call) as done, so leaders can see accounts and teams activity in the same dashboard

## Show & Swap read, round 2

_A NEW partner, a blind read. What landed differently from v1?_

- **Feels like a real product, or a mockup?** [My own answers as I changed partner] It still feels a bit like a mock up but the actionability of risk makes it feel much more real, as well as being able to track progress
- **Where interactivity fell short:** I cannot see how churn changes AFTER my actions - e.g. I cannot see if an account has improved health after the action or not. An onboarding call should increase the use of key features, how do I know there is at least correlation?
- **Would they show it to a VP?** Not yet - because it does not show that a hypothesis (intervention) is tested, it only collates a snapshot and a list of events. It feels more like a tracker than an insightful dashboard at this stage
